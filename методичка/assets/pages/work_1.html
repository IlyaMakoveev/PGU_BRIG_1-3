Работа №1

Создание и оформление списков и таблиц в HTML

Цель работы

Познакомиться с основными элементами HTML, научиться структурировать текст, формировать списки и создавать таблицы для отображения информации на веб-странице .

Задание

Создать HTML-страницу, которая будет содержать списки и таблицы в соответствии с выданным заданием.

Получить задание у преподавателя

Индивидуальное задание на разработку HTML-страницы выдается преподавателем на занятиях. Примеры заданий находятся в конце страницы.

Разработать структуру HTML документа

Изучите структуру, основные элементов HTML документа и основы CSS.

Оформить текст

Основной текст сайта пишется в теле <body>. Используйте тэги форматирования, абзаца и переноса.

Организовать списки в HTML

Ознакомьтесь с теорией по оформлению списков. Организуйте их согласно выданному вам варианту. Продемонстрируйте максимальное количество возможностей оформления списков (нумерованные, ненумерованные, вложенные, с использованием символов).

Создать таблицы в HTML

Изучите теорию по созданию таблиц в HTML. Продемонтрируйте свои навыки и преобразуйте таблицу (объедините необходимые ячейки, поиграйтесь с границами и заливкой ячеек).

Примечание

Не забудьте использовать CSS для оформления дизайна вашей HTML страницы.
