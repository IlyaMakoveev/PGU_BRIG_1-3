Работа №3

Создание портфолио

Цель работы

Создать собственное портфолио, используя HTML и CSS.

Задание

Создайте одностраничный сайт-портфолио, используя HTML и CSS. Сайт должен содержать:

  • Шапку с навигацией
  • Секцию с приветствием
  • Галерею работ
  • Информацию о себе
  • Блок контактов
Референс — adhamdannaway.com.

Подготовка структуры проекта

Создайте папку проекта и внутри нее:

  • index.html – главный файл HTML.
  • styles.css – файл стилей.
  • Папка images/ для изображений (если нужны).

    • Базовая структура HTML

    В index.html создайте основную разметку

    <header>

    Шапка сайта (обычно содержит логотип, навигацию).

    <nav>

    Блок навигации (меню).

    Сейчас делаем только внешний вид навигации. Ее функциональностью мы займемся в следующей лабораторной.

    <main>

    Основное содержимое страницы.

    <section>

    Секция (логический раздел контента).

      Секции нужны для навигации.

    • #hero — приветственный блок,
    • #work — портфолио,
    • #about — информация о себе,
    • #contact — контакты.

    <footer>

    Подвал страницы (копирайт, ссылки на соцсети и т. д.).

    Стилизация в CSS (styles.css)

    Добавьте стили на каждый блок, секцию страницы.
