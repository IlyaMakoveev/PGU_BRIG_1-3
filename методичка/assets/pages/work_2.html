Работа №2

Работа с изображениями в HTML

Цель работы

Научиться работать с изображениями в HTML.

Задание

Выполнить различные упражнения, которые помогут понять, как вставлять изображения на веб-страницу, применять стили и эффекты, а также использовать SVG для создания векторной графики. В результате выполнения всех заданий вы должны создать веб-страницу, на которой будут продемонстрированы все изученные техники.

Вставка изображений в теге <img>

Используйте тег <img> для вставки изображений на вашу веб-страницу. Убедитесь, что вы указываете атрибуты src (путь к изображению) и alt (альтернативный текст для доступности). Попробуйте отобразить выбранную вами картинку в нескольких размерах.

Также попробуйте разные способы вставки изображения

  • Картинка находится в папке с основным файлом index.html
  • Картинка находится где-то на компьютере (пропишите пусть к файлу с изображением)
  • Вставьте изображение по ссылке из интернета

    • Вставка изображений через <svg>

    С помощью этого способа добавьте иконку и прикрепите ссылку на сайт, подходящий к ней.

    Вставка через CSS фонового изображения

    Для добавления фоновых изображений используется CSS-свойство background-image.

    Наложение фильтра на изображение

    Наложите несколько фильтров на изображение.

    Создание рамки вокруг изображения

    Используйте CSS для добавления рамки к изображению. Настройте ее цвет, толщину и стиль.

    Вставка изображения в таблицу

    Добавьте столбец в одну из таблиц из прошлой лабораторной работы и вставьте туда картинки.

    Эффекты наведения на изображение

    Наложите на одну из картинок Hover эффект.

    Картинка в виде ссылки

    Сделайте из картинки ссылку, ведущую на какой-нибудь сайт.
